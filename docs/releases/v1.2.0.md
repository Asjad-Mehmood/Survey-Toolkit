## Survey Toolkit 1.2.0

**Help and support, built in, and safer links.**

- **Help** in the sidebar (or **F1**): What's new, the guide, keyboard shortcuts, **Report a
  problem** (the contact form opens with the Toolkit and its version filled in), the log and the
  open-source licences.
- **A clear message when something goes wrong.** An unexpected error shows a short notice with
  **Report a problem**, and is written to the Toolkit's log next to the install steps, so one file
  has everything when you write to us.
- **Auto Drafting and Folders** pages have the new Help too: Auto Drafting's **?** and F1, and
  Project Folder Manager's More menu with What's new, Report a problem and the licences.
- **Safer links.** A link clicked inside an app opens only web pages and email; anything else is
  ignored, so a link can't start something on your PC.
- **Ready for the new sign-in page.** When an app inside the Toolkit has to sign in again on the
  website's own sign-in address, it stays in the Toolkit's window.
- The publisher in Windows' list of programs is now **exceltokml.com**.

**Already have the Toolkit?** It updates itself to 1.2.0 the next time you open it.

**"Windows protected your PC"?** The Toolkit isn't signed with a paid certificate yet. Press
**More info**, then **Run anyway**.
