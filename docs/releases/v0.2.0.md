## Survey Toolkit 0.2.0 (beta)

**Install and update from the Toolkit.** Each tool's card now has **Install**, **Update** and
**Uninstall**.

- Every tool is installed with its own official installer or download, from exceltokml.com or its
  GitHub releases, and its **SHA-256 checksum is checked first**. A download that doesn't match is
  deleted and nothing is installed.
- **A tool that is open is never updated.** The Toolkit asks you to close it first, so you never
  lose unsaved work.
- **RoadPro** is installed as an AutoCAD bundle: AutoCAD loads it by itself every time it starts,
  with no APPLOAD and no Startup Suite.
- **Project Folder Manager** is installed into the Toolkit's folder with a Start menu shortcut.
  Updates keep your settings file.
- After every install the Toolkit checks the new version is really there.
- Uninstall uses each tool's own uninstaller, after asking you.
- Excel to KML and Traverse & Level open by themselves after they are installed or updated.

If something goes wrong, the reason is shown on the card and written to
`%LOCALAPPDATA%\Survey Toolkit\toolkit.log`.
