## Survey Toolkit 0.6.2 (beta)

**Project Folder Manager 7.** The Toolkit now installs and updates the new Project Folder Manager:
a proper Windows program with its own installer, listed in Settings → Apps, with a cleaner look,
a manual and a folder list that follows the disk by itself.

- **Already have 6.2?** It shows **Update**. The Toolkit installs version 7, then removes the old 6.2
  copy it installed and its Start menu shortcut. Your 6.2 settings file is kept: the first time
  version 7 opens, its start page offers to bring those settings in.
- A 6.2 copy you unzipped yourself somewhere else is left as it is.

Also in this version: drop-down lists open inside the apps (from 0.6.1).
